About This App

The Student Study Scheduler is a web-based application designed to help students effectively manage their study time across multiple subjects. It allows students to log their available hours, set deadlines, and visualize their study plans using interactive charts.

Key Features:

  • Plan and allocate study time per subject
  • Track deadlines for each subject
  • View study distribution using a pie chart
  • Clean and mobile-responsive interface

Technologies Used:

  • HTML5, CSS3, JavaScript
  • Chart.js for visualizing data
  • LocalStorage for saving your data
