# 📚 Student Study Scheduler

A responsive web-based application to help students effectively manage their study time across multiple subjects. 

Plan your hours, track deadlines, and visualize your study distribution with interactive charts.

## ✨ Features

- **Plan and allocate study time** per subject
- **Track deadlines** for each subject 
- **View study distribution** using interactive Pie Chart with Chart.js
- **Data Persistence** using LocalStorage - data won't be lost on refresh
- **Clean and mobile-responsive interface** - works on phone and desktop
- **Simple and user-friendly UI** with gradient design

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript
- **Charts**: Chart.js for data visualization
- **Storage**: Browser LocalStorage API
- **Design**: Custom CSS with responsive layout
